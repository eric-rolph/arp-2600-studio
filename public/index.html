Using 2600 Studio

Play

Press Power on. Play the on-screen keyboard or use A W S E D F T G Y H U J K. Z and X shift octaves. Dock keys keeps the keyboard visible while you scroll. Phones show two octaves at a time.

The synth plays one note at a time, with priority given to the last key pressed. DUO sends the lower note to VCO 1 and VCO 3, and the upper note to VCO 2. Both notes share the envelopes. Hold Gate to trigger an envelope without playing a key.

A connected MIDI keyboard can send notes, pitch bend, modulation and sustain. Patch memory has starting sounds for bass, leads, percussion, pads and voice processing. The text below the list describes each patch.

Microphone

Enable the microphone, then press Patch mic in the External input section. Click any green-ringed input to connect it. You can also drag from MIC OUT, or select Microphone in the routing list. One microphone output can feed several inputs at once.

Mic gain controls the signal level. Raise the destination's level or modulation fader to hear its effect. MIC OUT carries audio. ENV carries your voice's loudness and is more useful for envelope, pitch or gate control. The amplifier must be open, either from a held key or its Initial fader, to hear an audio patch.

Use headphones to avoid feedback. Select "Droid · voice + circuit", then enable Microphone. Your voice enters the ring modulator. Its envelope controls the amplifier and filter. Speak while playing to combine the two signals.

The green trace shows microphone input. The orange trace shows the output. Voice patches need microphone input to make sound.

Patch cables

Click a jack and move the pointer to draw out a cable. Compatible jacks have green rings. Click one to connect, or drag from one jack and release over the other. You can start at either an output or an unconnected input.

Each input accepts one cable. Connecting another replaces it. Click a connected input to unplug it and restore its printed internal source. Press Escape or click outside the jacks to cancel a loose cable.

You can also tab to a jack and press Enter or Space. "Show signal path" has a routing list with connection and removal controls. Double-click a fader to reset it. Arrow keys adjust a focused fader.

Patch library

Browse library searches patches by sound, instrument and technique. Filter by category or play mode, keep favorites, and preview sounds without changing your patch. Microphone previews use a generated test signal. Load patch applies the selected settings. Save current patch adds a memory with tags and notes; Edit name & notes changes a saved memory. Download bank exports your patches, favorites or search results. Import bank adds memories and numbers duplicate names. Banks contain settings, not tape recordings.

2600 banks can also be imported into TONTO Studio.

Record and export

Record captures the synth and a separate microphone track. Stop keeps the take. Raise DRY VOICE to mix in the microphone recording before the filter and ring modulator. You can play existing takes while recording another.

Tape speed changes pitch and duration together. Reverse changes playback direction. Saturation adds distortion. Wow and flutter add slow and fast speed variation. Each take has its own speed, start time and level controls.

Export mix saves a stereo 16-bit WAV with the current tape settings. Synth WAV and Voice WAV save the original tracks. Recordings stay in memory. Save session downloads the patch, tape settings and all takes as full-resolution audio. Open session restores that file in this studio. Save or export before closing or reloading; patch JSON alone does not include recordings.

Save stores the current patch in this browser. Export saves it as a JSON file that you can import later.

Audio controls

Panic releases held notes and clears feedback and reverb. Press Microphone again to disconnect the input. If the browser denies microphone access, change the site's permission and try again. Use Chrome or Edge for MIDI.

Model notes and references

This app models the ARP 2600's signal routing and controls. It is an independent project with no affiliation to ARP or Korg. Its sound has not been measured against a physical 2600.

The oscillators run at twice the device sample rate. The filter and spring reverb are digital approximations. The model does not reproduce measured component tolerances or the differences between the 4012 and 4072 filters. Feedback connections introduce a processing delay.

Duophonic mode splits oscillator pitch between two notes with shared envelopes. Voltage ranges and the panel layout are adapted for the screen. The tape recorder uses resampling, saturation and speed modulation. It does not model magnetic tape hysteresis.
